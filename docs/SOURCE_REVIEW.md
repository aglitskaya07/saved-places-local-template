# Повторная проверка источников

Это порядок ручного разбора в Codex. Автоматическое распознавание места по интерьеру не подключено.

1. Выбирать публикации без карточек, с неполным разбором и с карточками без адреса. Перед поиском проверить существующие связи: нужное место могло уже попасть в гайд из этого же ролика. Статус публикации и статус отдельного места различаются.
2. Прочитать полную подпись. Каждое упоминание аккаунта проверить в контексте: посещённый магазин, мастерская, организатор, автор, рекламодатель или кредит фотографии. Посещённое место можно сохранить без оценочной рекомендации автора. Простое название бренда одежды на человеке не доказывает посещение его магазина.
3. Прочитать все подготовленные OCR-кадры и расшифровку. При неполной вывеске, номере дома или названии филиала открыть исходный кадр: OCR может пропускать буквы. Приписывать музыке географический смысл нельзя. При доступных метаданных отдельно проверить геотег и отмеченные аккаунты; их отсутствие не восполнять догадкой.
4. Проверить кандидата по официальному сайту: название, район, адрес, конкретный филиал. Сопоставлять совокупность признаков. Сходная услуга или похожий интерьер сами по себе не подтверждают, что найден именно объект из ролика.
5. Сохранять доказательство из исходного поста отдельно от внешней проверки и выводов системы. Если автор предлагает получить адрес через комментарий или личное сообщение, явно записать этот пробел. Автоматически писать автору нельзя.
6. Проверить город по содержанию. Сохранение в коллекции Copenhagen может показывать Brooklyn. Подтверждённое исправление города делается отдельно при ручном разборе с сохранением настоящего членства публикации в Instagram-коллекции. Не создавать фиктивную принадлежность и не ослаблять проверку города при обычном импорте.
7. Старые даты мероприятий обозначать как прошедшие. Названная постоянная площадка может остаться полезной, но старое мероприятие нельзя представлять доступным сейчас. Общая сеть или район могут не иметь единственного адреса.
8. Перед записью сохранить резервную копию. При дополнении источника сохранить прежние места и пользовательские поля; адресное уточнение не должно оставлять дубликат. Добавить фото с атрибуцией, проверенные координаты либо явный пробел. Валидировать изображения, собрать локальный HTML через saved_places.build и проверить карточки в браузере через file://.

Итог проверки хранить в приватном отчёте: идентификаторы источников, просмотренные материалы, новые находки, оставшиеся кандидаты и причины неопределённости. Не считать уже существовавшую карточку новой находкой. Число перепроверенных публикаций не является измерением полноты распознавания всех мест.
