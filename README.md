# Saved Places Local

Личный HTML-гайд из своих Instagram-сохранений. Проект рассчитан на запуск в Codex на Mac: он получает посты, готовит кадры и речь, а Codex извлекает и проверяет места. Готовый `guide/index.html` открывается двойным щелчком. Сервер и хостинг не нужны.

## Начать

1. Создай свою копию этого репозитория через **Use this template** и скачай её на Mac.
2. Открой папку проекта в Codex. Вставь запрос из [START_HERE.md](START_HERE.md).
3. Codex проверит зависимости и подготовит окружение. Затем открой **Подключить Instagram.command**. Вводи пароль и 2FA только в локальном Терминале.
4. Пройди [первую подготовку до десяти публикаций](#выбор-коллекций-и-обновление): выбери коллекцию и назови город. После проверки небольшой выборки запускай **Обновить сохранения.command** для всего выбранного объёма. Названия городов произвольные; готовых личных коллекций в шаблоне нет.
5. Попроси Codex разобрать новые материалы по [правилам](docs/SOURCE_REVIEW.md), проверить найденные места и собрать гайд.
6. Открой **Собрать и открыть гайд.command**. Результат хранится в `guide/index.html` рядом с локальными изображениями и шрифтами.

При следующем обновлении повтори шаги 4–6. Успешные разборы сохраняются. Интернет нужен для Instagram, проверки мест, получения отзывов и внешних карт. Уже собранный HTML и скопированные фото читаются локально.

## Подключение Instagram: instagrapi

Для чтения сохранённых коллекций используется открытая Python-библиотека [instagrapi от subzeroid](https://github.com/subzeroid/instagrapi). [Документация по коллекциям](https://subzeroid.github.io/instagrapi/usage-guide/collection.html) описывает возможности библиотеки. В этом шаблоне подключение, чтение страниц и остановка при ограничениях реализованы в `saved_places/probe.py` и `saved_places/update.py`.

Это неофициальный доступ к Instagram через свой аккаунт. Отдельный API-ключ Instagram, приложение в Meta Developers и подписка на HikerAPI для этого шаблона не нужны. Ключ Apify, если используешь отзывы, настраивается отдельно и к входу в Instagram отношения не имеет.

### Установка и первый вход

Отдельно скачивать репозиторий instagrapi не требуется: библиотека версии `2.18.18` указана в `pyproject.toml`, а зависимости закреплены в `uv.lock`. В Терминале, находясь в папке своей копии Saved Places Local, выполни:

```sh
uv sync --frozen
uv run --frozen python -m saved_places.doctor
uv run --frozen python -m saved_places.probe --limit 5
```

Если `uv` или другие зависимости ещё не установлены, начни с запроса для Codex в [START_HERE.md](START_HERE.md). После установки вместо последней команды можно открыть **Подключить Instagram.command**.

Программа попросит имя пользователя Instagram, пароль и текущий код из приложения двухфакторной аутентификации. Если 2FA отключена, оставь поле кода пустым и нажми Enter. Пароль и код вводятся только в локальном Терминале; символы не отображаются. Не вставляй их в чат или в файлы проекта.

После входа появится список коллекций. Выбери одну для проверки: программа прочитает до пяти публикаций и попробует временно загрузить одно видео. Успех этой проверки означает доступ к материалам; извлечение мест выполняется следующим шагом. Если в выборке нет видео, загрузка видео остаётся непроверенной — выбери коллекцию с рилсами.

Повтори эту же команду: должно появиться «Проверяю сохранённый вход…». Для проверки новых сохранений добавь рилс в выбранную коллекцию и запусти проверку снова. Она сравнивает небольшую выборку; полное чтение выполняет обновление ниже.

### Выбор коллекций и обновление

Первую подготовку ограничь десятью публикациями:

```sh
uv run --frozen python -m saved_places.update --configure
```

Укажи номера коллекций через запятую и город для каждой. Для первого разбора выбери одну коллекцию. Команда прочитает её целиком, но подготовит к разбору не более десяти оставшихся публикаций. Передай материалы Codex по [правилам разбора](docs/SOURCE_REVIEW.md) и проверь результат в локальном HTML. Затем весь оставшийся выбранный объём можно подготовить так:

```sh
uv run --frozen python -m saved_places.update --all --workers 2
```

Эту же команду выполняет **Обновить сохранения.command**. Выбор коллекций сохраняется. Для изменения выбора снова используй `--configure`; для появления недавно созданных коллекций сначала повтори `probe`, чтобы обновить их список.

### Сессия и восстановление доступа

Сессия хранится в `private/` внутри [локальной папки данных](#хранение), отдельно от репозитория и HTML. Она позволяет повторять обновления без ввода пароля. Файл сессии даёт доступ к аккаунту: не передавай его коллегам и не загружай на GitHub. Для другого Instagram-аккаунта создай отдельную копию проекта, чтобы не смешивать сессии и коллекции.

| Что произошло | Что делать |
|---|---|
| `uv: command not found` | Попроси Codex установить зависимости по `START_HERE.md`, затем повтори установку. |
| Требуется локальный Терминал | Открой **Подключить Instagram.command** или выполни команду входа в обычном Терминале. |
| Неверный пароль или код 2FA | Проверь вход в приложении Instagram. Повтори вход с актуальными данными локально. |
| `LoginRequired` или сообщение о неполной сессии | Выполни явный повторный вход командой ниже. |
| `ChallengeRequired` или запрос подтверждения | Открой Instagram и заверши проверку личности. Затем выполни явный повторный вход. Если проверка повторяется, остановись и передай Codex только название ошибки. |
| Ограничение запросов, `PleaseWaitFewMinutes`, HTTP 429 | Останови обращения и повтори позже с учётом сообщения Instagram. Не запускай вход по кругу; точное время восстановления неизвестно. |
| Сеть недоступна или видео не загрузилось | Проверь соединение и доступность поста в Instagram. При недоступном видео разбор остаётся неполным; список коллекций сам по себе не подтверждает доступ к видео. |

Явный повторный вход после устранения причины:

```sh
uv run --frozen python -m saved_places.probe --login --limit 5
```

Используй то же имя пользователя. Программа сохраняет параметры устройства при обновлении сессии. После успешной проверки снова запусти обновление. При ошибке программа показывает шаг, тип ошибки и путь к локальному отчёту. Для диагностики сначала передай Codex название ошибки; отчёт может содержать личные сохранения и не предназначен для публикации.

Работоспособность на каждом аккаунте проверяется отдельно. Разработчики instagrapi предупреждают, что неофициальный доступ зависит от ограничений Instagram, состояния сессии и проверок аккаунта; установленная библиотека не гарантирует успешного входа.

## Что умеет локальная версия

Города, поиск, подборки по занятиям, отдельная рубрика «Истории города», по восемь карточек на странице, фотографии, описания, исходные посты, проверка адреса и отзывы с указанием источника. Карта открывается внешней ссылкой. Заметки, внесённые в локальную базу через Codex, попадают в HTML; редактирования через HTML-интерфейс пока нет.

Разбор мест требует участия Codex. FFmpeg готовит кадры и звук, Apple Vision читает надписи, Whisper распознаёт речь. Эти инструменты сами не проверяют заведения. Подготовка материалов не означает завершённого разбора.

Для отзывов опционально нужен свой Apify API token. Codex поможет сохранить его в `private/providers/apify.json` внутри локальной папки данных. Не отправляй ключ в чат. Если ключа нет, гайд всё равно собирается; отсутствие отзывов обозначается явно. Каждый запуск Apify имеет лимит расходов; согласуй бюджет до запуска.

## Хранение

Каждая копия проекта использует отдельную папку:
`~/Library/Application Support/Saved Places Local/<идентификатор папки проекта>/`.
В ней находятся база, подготовленные материалы и `private/` с сессией Instagram. Эта версия не читает сессии другого проекта Saved Places. При перемещении проекта изменится идентификатор папки; перед переносом посмотри путь командой ниже и задай `SAVED_PLACES_DATA_DIR`, если хочешь сохранить прежнее хранилище.

```sh
uv run python -c 'from saved_places.probe import DATA_ROOT; print(DATA_ROOT)'
```

`guide/` исключён из Git. Если передаёшь кому-то эту папку, он сможет прочитать включённые в HTML места, заметки и отзывы: у обычного HTML-файла нет авторизации. Передавай весь `guide/` для сохранения фото и шрифтов. Для запуска коллегами делись ссылкой на шаблон, а не своими данными.

## Зависимости и команды

macOS, Python 3.12, `uv`, FFmpeg (`ffmpeg` и `ffprobe`), инструменты разработчика Apple (`swiftc`). Для речи: `whisper-cli` и модель `ggml-small.bin` в `~/.cache/whisper-cpp/`, либо команда `whisper` с моделью `tiny`. Codex может помочь установить недостающее. Если речь недоступна, разбор должен оставаться помеченным как неполный.

```sh
uv sync --frozen
uv run python -m saved_places.doctor
uv run python -m saved_places.probe
uv run python -m saved_places.update --all --workers 2
uv run python -m saved_places.review /полный/путь/reviews.json
uv run python -m saved_places.build --open
uv run pytest -q
```

Разбор импортируется массивом объектов `Review`: `source_id`, `city`, `extraction` и опциональный `verified`. Формат описан в `saved_places/review.py` и `saved_places/store.py`. Дополнения карточки (фото, отзывы, тип материала) сохраняются через `saved_places.enrichment.save_details`. Для исторического сюжета используй `content_kind: "city_story"`.

Доступ к Instagram неофициальный: библиотека может перестать работать или потребовать подтверждение входа. При ограничении обращения прекращаются; повторная авторизация выполняется локально с `--login`. Новый аккаунт обязательно проверить на небольшой выборке перед массовой обработкой. Тесты шаблона используют искусственные данные; работоспособность входа на каждом аккаунте проверяется отдельно.
